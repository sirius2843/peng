# 小鹏哥内容工作台

本地可用的网页与服务端。界面参考用户提供的乐伴页面，省去人设学习、复杂设置、右侧面板和定时任务。GitHub 尚未推送，公网尚未部署。

## 打开

需要 Python 3.11 或更新版本，无第三方 Python 依赖。

```sh
python3.11 server.py --port 16688
```

打开 http://127.0.0.1:16688。当前机器已准备 `.local` 私有语料和通联凭据，页面右上角可保存 DeepSeek API Key。

## 使用

- 按栏目生成：每日必看、盘中实操、风口收评、本周来信、行业/事件点评；补充想法可留空。
- 新撰写文章：输入事件、行业或写作想法，采用小鹏哥判断框架和表达。
- 历史原文仅在服务端检索，前台不展示原文列表或近期原文。
- 每个栏目有内容概要与生成逻辑，点击调整后可保存；生成使用服务端保存的最新说明。
- 运营素材可以编辑、新增或移除；每次勾选后原样追加，默认不选，不由模型编造运营入口。
- 蒸馏结果：判断框架、观点台账、场景打法库、栏目声音。按小类查看，支持认可、调整、补充、暂停，以及查看原文和恢复旧版本。
- 生成稿可复制、编辑保存、提交修改要求。资料与审阅默认折叠；仅用于辅助审核，不能证明作者满意。

初次打开不放样例文章，也不自动打开旧稿。历史稿页面按栏目筛选和搜索，可重新打开、编辑、审阅和提交学习反馈；旧模拟记录保留在私有存储中，不展示为正式稿件。

## 生成如何工作

1. 确定栏目和北京时间截点。每日必看默认取当天 08:45 与当前时间中较早者；盘前不可带入当天午间数据。
2. 选择相关历史规则、同栏目原文、正反场景和观点轨迹。档案日期未核验，保守排除同日与未知日期样本，历史数字不当期沿用。
3. 请求通联日终行情、财联社公开新闻摘要、东方财富公开研报摘要；通联缺项时尝试东方财富/腾讯历史指数交叉验证及东方财富行业涨跌备用报价；行业资金只读取通联。每日必看还读取 Yahoo Finance 免费海外报价。资料时点、来源和缺口随稿保存。
4. DeepSeek 同时接收核心提示词、栏目规则、声音指南、检索案例及当次事实。正文不显示后台规则编号。补充想法是素材；“本人当期观点”在本人明确勾选后按 author_confirmed 使用，优先于历史观点，每行一条判断、选择期限。“真实信号”需本人填写资产、工具、结果和北京时间观测时间，不能晚于稿件截点。观点不会自动变成已核验客观事实。
5. 保存正文、句子与证据对应、判断依据、期限和复核条件，以及单列的 new_judgments。本人可逐条确认，再带入下一篇当期观点，重新确认时效。机械审查发现错误时补改一次；仍不通过的稿件保留并标记待复核，不假称可发布。
6. 机械审查通过后执行一次非思考模式的声音复核：参照真实同栏目样本、声音指南、本人调整和统计基线，列出最多三处偏离并改写；再做机械证据复查，失败即保留改写前稿。初次输出、机械修复和声音改写前稿随记录保存。对照最近同栏目生成稿的开头和章节，提示模板化。正文组织围绕当天矛盾，不固定为“指数—板块—明日”三段。

DeepSeek 使用官方 OpenAI 兼容 `/chat/completions`，默认 `deepseek-flash`、JSON 输出、默认输出预算12000和非思考模式。页面可配置模型、2000—64000输出预算和思考模式，识别 finish_reason=length 后单独报告截断，不泄漏远程错误体。模型也可通过 `DEEPSEEK_MODEL` 更换；账户可用模型通过配置页测试连接检查。接口依据：[DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)。未提供密钥，因此尚无真实 DeepSeek 出稿和作者验收结果。

## 数据范围与当前边界

- 通联：三大指数、沪深 A 股成交额及交易日对比、涨跌家数、通联一级行业领涨领跌。沪深成交口径不含北交所、B 股、ETF；不把行业排行与 ETF 分类混排。
- 当前凭据可读取日终接口，盘中快照接口返回权限不足。16:00 前只取上一完整交易日；盘中实操以行业消息和条件判断为主，明确参考日，不生成假实时价格、BOLL 或专有工具信号。
- 财联社：公开首页新闻摘要，过滤截点之后内容，不读取付费栏目。媒体报道不等于公告逐条核验；未匹配到消息时显示缺口。
- 研报：参考 report-cli 查询方式，取得公开详情摘要；尚未接入 PDF 全文/私有研报 Clip 库。只有日期的报告按当天结束后才可用，本版本保守排除同日报告。
- 风口收评按实际资料覆盖指数、量能、领涨、领跌、消息、主力资金与后续条件。缺项由服务端设置 coverage_exemptions，省略缺失部分并记录缺口；全部资料都缺失才停止。盘后消息不得反向解释白天行情。
- 行业资金读取通联 `market/getMktInstEqudV1` 的 `netMainInflow`，与涨跌同为中信一级行业；涨跌幅由小数换为百分比，资金由元换为亿元。缺失值不当作零，不编资金占比或大单拆分。日期、分类与数值检查属于来源校验，不声称独立机构同口径复核；不接入 Tushare。
- Yahoo Finance 免费源：标普500、道琼斯、纳斯达克、英国富时、德国DAX、美国十年国债收益率、WTI原油期货、COMEX黄金期货。指数只取截点前已收盘交易日；油金取完整小时报价，明确期货代理，非现货/正式结算价。日期陈旧或请求失败时排除并显示缺口。
- 后续可增加公告、财联社电报、证券报和同花顺适配器，以及用户授权的研报全文接口；以当次资料包中成功取得的来源为准，不将接入适配器等同于每次都能取到数据。

## 私有配置与 GitHub

`.local/` 包含原文、检索标签、规则证据、通联 token、DeepSeek key、历史稿数据库和运行检查结果，全部忽略上传。前端仅知道“已配置/未配置”，不获取凭据。API 不返回 key，静态路由只允许明确列出的网页资源。

新机器部署需从用户私有备份恢复 `.local` 中的语料文件（`corpus_index.json`、`article_metadata_v2.json`、`framework_rules.json`、`contrast_cases.json`、`view_ledger.json`、`language_baseline.json`，`distillation_v3.json`，可选 `sample.json`）；不在公开 GitHub 中提供全量原文。凭据用环境变量或私有卷提供。

| 变量 | 用途 |
| --- | --- |
| `STUDIO_DATA_DIR` | 私有数据目录，默认 `.local` |
| `WMCLOUD_TOKEN` | 通联 token，或目录内 `wmcloud_token.txt` |
| `DEEPSEEK_API_KEY` | DeepSeek key，或页面配置的 `deepseek.json` |
| `DEEPSEEK_MODEL` | 模型覆盖值 |
| `APP_ACCESS_PASSWORD` | 对外部署的访问密码 |
| `PUBLIC_ORIGIN` | 对外域名，例如 `https://studio.example.com` |

GitHub 保存代码；凭据和数据在服务端私有存储。GitHub Pages 本身不运行这个 Python 后端，因此正式网站需要同域服务端或带反向代理的部署，不能只上传静态网页便获得安全的数据调用。

容器示例（私有目录须提前恢复）：

```sh
docker build -t xiaopeng-studio .
docker run --env-file .env -p 16688:16688 -v "$PWD/.local:/data" xiaopeng-studio
```

生产环境通过 HTTPS 反向代理提供域名访问。外部绑定必须设置访问密码与 `PUBLIC_ORIGIN`；应用提供登录会话、同源与 CSRF 检查。当前预览只绑定本机。

## 验证

```sh
python3.11 -m unittest discover -s tests -v
```

54 项测试覆盖版本保留、并发冲突、反馈范围、模拟稿排除、规则暂停恢复、最新改稿再生成，以及盘前未来资料阻断、错误证据引用、虚构本人记录、历史检索时点、模型调用契约与异常处理。模型响应使用测试替身，不等于真实 DeepSeek 出稿。通联三指数、无主题过滤的财联社新闻、八项海外报价，以及东方财富/腾讯三指数历史对照已实读验证；通联行业资金已实读验证：2026-10-08 共31个中信一级行业均返回主力净流入，18条涨跌/资金重点材料进入收评生成链路。详见 [本轮优化核对](OPTIMIZATION.md)。

## 本人校准与学习

文章每次编辑保存都追加版本，保留初稿、修改稿和当次资料、知识版本。点“提交修改稿，帮助助手学习”，确认修改类别、填写希望以后如何处理的一句话，可选择仅留档或供同栏目相似情形参考。判断、期限与仓位、信息选择、声音、结构和运营分别记录；不会从文字差异擅自推断修改原因。

只有真实稿件、本人明确提交并确认适用范围的反馈进入下一次检索。演示反馈不参与；暂停后立即停用。多次类似反馈不会自动改变全局规则，需要本人在判断框架里明确确认。改进依赖检索与提示词，不是模型自动训练。

`.local/studio.sqlite` 是校准与版本记录的权威存储；`.local/author_feedback.json` 是随修改/反馈导出的审计副本。迁移必须恢复数据库、preferences.json 和私有语料，不能只复制初始蒸馏 JSON。旧版已丢失的中间编辑和原因无法恢复。

## 场景与声音检索

场景选择为平稳、缩量分化、破位、反弹、高位拥挤，映射原蒸馏标签，独立检索成对案例并遵循本人暂停/调整状态。没有补充想法及本人输入时，新闻按时间取，避免固定科技医药偏置；取得行情后，用实际领涨领跌行业补充历史检索主题，新闻保持全市场筛选。

生成携带同栏目篇幅中位数、句长中位数、编号率、问句标题率和第一人称率。统计只作参照，偏离作为提醒，不强迫凑句子。没有风口收评本人样本时明确使用每日必看的表达参考，不冒称已学习付费收评风格。

### 共享当期观点与真实运营素材（2026-10-09）

创作页最上方统一维护更新日期/时间、盘面场景（含其他）、大盘观点与可添加的行业观点。每个方向分别保存期限、真实BOLL/龙线/底信号和观测时间。本人核对后点击“保存共享观点”，所有栏目后续生成共用。观点可留空，仍按栏目与蒸馏规则生产；当日新闻不因为填写了观点而静默缩小到所填行业。本人当期取舍优先于历史观点，事实不能因观点改变；有反向新证据时列为待复核问题。新提出的判断仍供本人审阅。

已保存观点写入服务器数据目录的 `viewpoints.sqlite`，带递增版本、更新日期和保存时间。生成开始即冻结一版随稿留存，生成途中更新观点不会改掉正在生产的稿件；旧稿可点击“按最新观点更新这篇”，产生新记录并保留旧稿。保存时检查版本，两个页面同时保存只允许一个成功。按用户最新要求，暂按单人更新使用，关闭自动跨页面同步；保留服务端版本保存与手动载入。可查看更新记录、载入旧版供修改后另存新版本。未保存的输入仅在各自页面内，刷新会丢失。

两个人必须访问同一服务实例才能共用已保存数据。当前 `127.0.0.1:16688` 是本机预览：同一电脑不同标签页共用；另一电脑的 `127.0.0.1` 不是这台服务。部署到双方可访问的同一地址并使用同一持久数据目录后，才能跨电脑协作。

运营库现有12条财富圈真实素材，每条有文章ID、原始地址和原句；替换初始无原文依据的默认话术。12条素材已通过财富圈原始富文本逐句核对，已补入原文工作室入口；按本人指示，原文已有服务默认继续存在，直接可选，不存在由本人删除。勾选后原样附于文末，不选不加。调整后的文案和历史原句分别保留，已有自定义素材保留。

当期观点下方展示观点台账最新5条记录，两处共用记录、日期格式和排序规则。台账可按全部或方向筛选。盘面场景仅在选择“其他”时显示补充框；大盘与行业输入提示统一为“当前判断、建议仓位”。

日期核对：48篇台账/证据及素材所引用文章均从财富圈原始详情取得明确发布时间，已替代推断日期。最新判断和台账显示简洁日期，原始发布时间和核对依据保留于后台。所有下拉选择已统一为带选中标记、柔和边框的菜单，支持键盘和自动调整展开方向。

蒸馏页的“理念与方法”按七个语义分组呈现31张主卡；重复工具卡并入主卡补充区，原有证据和校准入口保留。研究方法/分资产研究与带日期的观点台账分开，卡片直接显示用途和边界；只有本人已确认/已停用两种徽标。分组配置在knowledge/profile_presentation.json，仅改变展示，不改写历史观点或知识ID。
